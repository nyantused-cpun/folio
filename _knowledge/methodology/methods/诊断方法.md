# 诊断方法（社区示例骨架）

> **社区示例**——四透镜诊断骨架，示例均为虚构（蓝海集团）。

## 四透镜

| 透镜 | 看什么 | 典型证据 |
|---|---|---|
| 业务 | 流程断点、动作成本 | 调研纪要、工时统计 |
| 数据 | 口径不一、断流、孤岛 | 报表对不上的场景 |
| 应用 | 系统覆盖、功能闲置、重复建设 | 权限/日志/访谈三方印证 |
| 技术 | 架构瓶颈、集成债、安全 | 接口清单、故障记录 |

## 归因链

现象 → 直接原因 → 机制原因（为什么会这样运转）→ 根因（谁受益/谁默认）。
诊断报告每条发现至少归到"机制原因"层；只写现象层等于没诊断。

## 使用纪律

- 四透镜分头取证、汇合归因；单透镜结论不得直接进方案。
- 每条发现标注证据来源与置信度；无证据发现降级为"待验证假设"。
