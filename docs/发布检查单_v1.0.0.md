```powershell

# 2. 关联并推送（本地已 commit 并打 tag v1.0.0，188 个文件）

git push -u origin master --tags

# 3. 仓库设置里加 topic：dsh-plugin（Settings → Topics）
```

推送后验证：GitHub 页面能看到 README 渲染 + v1.0.0 release 候选（tag 已就位，可点 tag 创建 Release，正文用 `RELEASE_NOTES.md`）。

## ③ 重启 dsh web + 插件运行级验证（10 分钟）

重启后**开一个新会话**，按顺序验证：

| # | 验证 | 预期 |
|---|---|---|
| 1 | 第一条消息后 | 收到【兰亭入口协议】提醒（folio-events 生效，已实证过一次） |
| 2 | 问「你有哪些 folio_ 工具」或直接说「用 folio_status 看下客户状态」 | 15 个工具可见可调，返回客户状态 JSON |
