# 快速上手：从 0 到第一份方案

> 目标：装完 Folio 后 30 分钟内，用虚构客户跑通「材料 → 方案 HTML → PPT」完整链路。
> 全程不需要配任何 API key（L0 等级）。

## 准备

1. 按 README 完成安装，重启 DSH（或其他 AI 宿主）；
2. 在 `inbox/` 放一份材料（虚构需求即可，比如一份 1-2 页的《蓝海集团数字化协同平台需求.docx》或 .md/.txt）。

## 第一步：接单入库

对 AI 说：

> 客户是蓝海集团，我刚把需求文档放进 inbox 了，帮我建档入库。

引擎会执行 `new` → 建档 → 归档 → 索引。完成后问一句：

> 上次做到了哪？接下来做什么？

看 AI 输出的客户上下文摘要——这是「建立记忆」在起作用。

## 第二步：生成 spec（框架分解）

> 按整体信息化规划的模板，把蓝海集团的材料拆成 spec 草稿给我看

AI 会调用 outline-to-spec / spec-gen，产出 spec.yml 草稿并**展示给你确认**。检查：
- 章节结构是否符合预期（现状痛点 → 建设目标 → 蓝图 → 实施路径 → 价值）；
- 每个数据点是否都能在原始材料里找到（防幻觉第一关）。

确认后 AI 写入 `confirmed: true`。

## 第三步：生成 HTML 方案

> 确认，生成 HTML 方案

引擎执行 html-build：HTML + 可编辑工程同源输出。产出在 `output/蓝海集团/蓝海集团_方案_v0.html`。

**到这里停下来**——HTML 先行是铁律：先看 HTML，改到满意，再谈 PPT。

## 第四步：确认后出 PPT

> HTML 我看了，整体 OK，改一下第 3 页的标题，然后出 PPT

AI 用可编辑模式改单页 → `pptd-build` 转换 → 在 `output/蓝海集团/` 拿到 PPTX。

## 第五步：收尾（会话结束必做）

> 今天到这里，保存

AI 执行 `save`：写客户记忆、归档窗口内文件、更新世界书图。

## 六条验证线索（跑完自查）

| 线索 | 怎么查 |
|---|---|
| 召回 | 新会话问"蓝海集团上次聊到哪"——应能接上 |
| 防幻觉 | spec 里每个数字都能在材料里找到出处 |
| 质量门 | 生成时 verify 报告 PASS；`review` 有输出 |
| 记忆 | `output/蓝海集团/` 出现；`_knowledge/clients/蓝海集团/` 有 context.md |
| 去 AI 化 | HTML 里没有"赋能/抓手/闭环"等禁用词 |
| 双格式同源 | HTML 和 PPT 内容一致（同一份 spec） |

