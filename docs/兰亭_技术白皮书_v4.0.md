| 层 | 内容 |

## 3. 工具管线

**一次工具调用，六道关卡按序过。**

```
参数校验（schema 不符直接拒绝）
  → pre-execute 门（守卫在这里拦违规）
  → 单调守卫（拦了不能翻案）
  → 执行体（subprocess 调 CLI）
  → post-execute（结果改写与阻断）
  → 结果通知（只读观察留痕）
```

前两道关卡可以拒绝调用，后四道保证结果可审计。

## 4. 事件与协议

**会话协议事件，把纪律变成机械。**

| 事件 | 时机 | 兰亭挂什么 |
|---|---|---|
| agent/session-start | 新会话建立 | 注入入口协议提醒 |
| agent/disposed | 会话关闭 | 扫描 agent.session.events 提取客户名，自动保存客户档案 |
| tools/pre-execute | 每次工具调用 | 拦非 CLI python 与 shell 直写 |
| fs/write-intent | 文件工具写盘前 | 拦产出物直写 |
