SECTION 4 · 事件

三个官方事件，把纪律变成机械

事件 时机 兰亭挂什么

tools/pre-execute 每次工具调用 拦非 CLI python 与 shell 直写
fs/write-intent 文件工具写盘前 拦产出物直写
