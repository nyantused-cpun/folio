## 1. 摘要

**一条命令装好 15 个原生工具，会话纪律机器执行。**

兰亭（Folio）是给咨询顾问用的材料生成引擎。它把「写方案、做 PPT、报价、记住每个客户」这套长活拆成五段，机械的部分全部交给确定性代码，你只做判断和确认。

| 指标 | 值 |
|---|---|
| 形态 | 宿主无关 CLI 内核 + 可选 DSH 插件增强层 |
| CLI 命令 | 87 个（发布面口径；主链 11 个） |
| DSH 原生工具 | 15 个 `folio_*`（开发线 17 个，随下一版同步） |
| 搜索工具 | 6 个 `search_*` |
| 图形 / 元素 / 主题 | 37 种 diagram / 39 种元素 / 7 套主题 |
| 起步成本 | 零 API key（L0）；1 个 embedding key 解锁语义召回（L1） |
| 平台 | Windows 10/11 + PowerShell + Python ≥ 3.10；**不需要 Node.js** |

## 2. 它解决什么问题

咨询顾问的日常是「长程任务」：一份方案从客户材料到最终交付，中间要检索历史、对齐口径、生成多个版本、还要记住每个客户的铁律。用 AI 做这件事，最大的风险不是「不够聪明」，而是**它会自己脑补、会忘掉早期约束、会把看起来对当成真的对**。

兰亭的做法是：**把能机械化的全部机械化**——

- 渲染、检索、解析、索引、守门、审计，全部由确定性代码执行；
- 模型只在理解、判断、写语言处出手；
- 每个关键环节都有机器门禁，错了就拦住，不靠提示词提醒。

## 3. 五段价值链

| 段 | 做什么 |
|---|---|
| **接入材料 Intake** | 客户建档、inbox 归档、招标 / PDF / PPT 解析、切片与双路索引 |
| **建立记忆 Chronicle** | 决策记录、客户档案、世界书、语义召回（零配置降级纯 BM25） |
| **应用方法论 Craft** | skill 路由 + 场景大纲 + 主题守卫 + 去 AI 化；方法论可换可组合 |
| **生成产出 Press** | spec 协议 → HTML / PPTX / DOCX / 报价同源双输出 |
| **守住质量 Proof** | confirmed 门禁、verify、独立审查、引用审计、美学 / 讲法观察 |

## 4. 三个卖点

### 卖点一：机械的交给代码，判断的留给模型

- **spec 门禁**：没确认过的 spec 渲染不出来（`confirmed: true` + 哈希 sidecar）。
- **主题守卫**：客户铁律写在 `decisions.md`，生成前自动注入 HEAD，长对话也不丢。
- **独立审查**：生成后另开一个 LLM 会话打分，fail-closed（不通过就退出非零）。
- **交付门**：定制页没过审查，不允许直接出 PPT。

### 卖点二：换方法论不换引擎

方法论做成可替换的 **Folio Packs**（YAML + SKILL.md）：市场营销、投资分析、战略咨询……换一套包就行，不用改引擎。`skills/packs-authoring` 是教你创作的 skill，问答式生成包骨架，不需要写代码。

### 卖点三：零 key 起步，按需解锁

- **L0**：不配任何 key 也能跑完整链路（HTML / PPT / DOCX / 报价）。
- **L1**：配 1 个 embedding key，解锁语义召回。
- **L2**：配读图 / 搜索 key，解锁独立 CLI 场景的视觉与联网能力。
- DSH 下由宿主原生能力覆盖读图、搜索、独立审查（`LLM_MODE=host`）。

## 5. 怎么装

```powershell
git clone https://github.com/nyantused-cpun/folio.git folio
cd folio
.\setup\install.ps1                  # 建 venv + 装依赖 + 生成配置 + 自检
# DSH 插件层（可选，建议装）：
.\setup\install-folio-plugins.ps1 -Install   # 15 工具 + 事件插件 + 守卫
# 重启 dsh web 后，新会话直接说「帮我做一份 XX 方案」
```

30 分钟跑通第一份方案：见 [快速上手](usage.md)。

## 6. 交付流水线

```
客户材料 → 接单入库 → 需求分析 → spec 草稿 → 用户确认
→ HTML（先行）→ 用户确认 → PPT / DOCX / 报价
```

**HTML 先行**是硬纪律：先把内容在浏览器里看对，再转其他格式。`deliver` 一键编排会在确认门前暂停。

## 7. 质量与安全

| 项 | 做法 |
|---|---|
| 内容审查 | 5 维打分 + 对抗 / 并行 / 增量 / 截图四种模式，fail-closed |
| 机械校验 | verify（结构 / 密度 / 版式 / 主题 / 引用）+ audit（14 模式）+ 体量棘轮 |
| 回归基线 | gold 渲染回归 37/37 |
| 读边界 | 读命令默认锁在工作区，越界需显式旗标 |
| 反序列化 | 未签名 pickle 一律拒绝 |
| 办公文档 | Word COM 强制禁宏 |
| 脱敏 | 17 词客户名 + 二进制办公文档解析 + 哈希钉 |

## 9. 已知限制（如实说）

- **Windows 优先**：macOS / Linux 安装脚本待补（欢迎 PR）。
- **Excel 带格式表格与公式**：尚未支持（欢迎 PR）。
- **`--shots` 截图目检**：需本机 PowerPoint；HTML / DOCX / 报价不受影响。
- **发布面数字口径**：文档写 90 模块 / 87 命令 / 191 测试文件，仓库实测 109 py / 91 add_parser / 192 test 文件；下一版统一。
- **context.md 正文仍是 AI 概括**：写入侧证据守门已就位，彻底解法是「事件摘录 + AI 摘要」双轨。
